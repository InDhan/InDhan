## 🏗️ How we build

**One platform, many products.** A shared control plane (we call it the *Family Model*) handles the common concerns — authentication, billing, subscriptions, credits, releases — so each product stays independent and focused on its users.

- **Backend** — NestJS, PostgreSQL, Prisma, Redis. HMAC-authenticated service-to-service.
- **Web** — Next.js (App Router), shadcn/ui, Tailwind.
- **Mobile** — Flutter.
- **Desktop** — Tauri (Rust + web).
- **Infrastructure** — Docker, nginx, Let&apos;s Encrypt, GitHub Actions, Google Cloud.

A few of the engineering principles I hold the team to:

- **UTC on the backend, timezones on the frontend.** One rule, every service.
- **Migrations only — never ad-hoc schema changes.** The database tells one story.
- **Local by default where privacy matters.** Signer, for example, never uploads your documents.
- **Short feedback loops.** Features ship behind flags and roll out in days, not weeks.
- **Write it down.** We maintain a rule book our engineers can read on day one.
